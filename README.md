# Sales Analysis Dashboard

## 📊 Project Overview

Sales Analysis Dashboard is a data analytics project built using MySQL and Tableau Public to analyze sales performance, profitability, quantity, orders, regions, categories, segments, and top-performing products.

The project analyzes 10,000+ sales records and converts raw sales data into meaningful business insights through SQL queries and interactive Tableau dashboards.

## 🛠️ Technologies Used

- MySQL
- SQL
- Tableau Public
- Excel
- CSV Dataset

## 📈 Key Analysis

- Total Sales
- Total Profit
- Total Quantity Sold
- Total Orders
- Monthly Sales Trend
- Regional Sales Performance
- Sales by Category
- Profit by Category
- Sales by Segment
- Top 10 Products
- Profit by Sub-Category

## 🗄️ SQL Analysis

MySQL was used for:

- Data cleaning and preparation
- Sales and profit calculations
- Order and customer analysis
- Category and sub-category analysis
- Regional performance analysis
- Identifying top-performing products

## 📊 Tableau Dashboard

The Tableau dashboard provides interactive visualizations including:

- KPI Cards
- Sales Trend
- Sales by Region
- Sales by Category
- Profit by Category
- Sales by Segment
- Top 10 Products
- Profit by Sub-Category

## 💡 Business Insights

The dashboard helps identify:

- Highest-performing regions
- Most profitable categories and sub-categories
- Top-selling products
- Monthly sales trends
- Differences in performance across customer segments
- Overall sales and profitability
